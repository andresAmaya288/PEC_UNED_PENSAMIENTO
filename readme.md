# Experimento de cerillas (Knoblich et al., 1999)

## ¿Qué es?

Esta es una práctica de la asignatura de **Psicología del Pensamiento** de UNED. Se trata de una tarea de **insight** basada en un experimento clásico de resolución de problemas.

## La tarea

Debes resolver **8 problemas** moviendo **solo 1 cerilla** en cada uno. El objetivo es transformar ecuaciones incorrectas en ecuaciones correctas usando **números romanos**. 

Por ejemplo: si ves `VI = VII + I` (que está mal), debes mover una cerilla para que quede correcta, como `VII = VI + I`.

## Cómo acceder

**URL:** https://andresamaya288.github.io/PEC_UNED_PENSAMIENTO/

Se recomienda usar **ordenador**, aunque también funciona en móvil (se aconseja hacer zoom para colocar mejor las cerillas).

## Instrucciones paso a paso

1. Abre el enlace anterior en tu navegador.
2. Introduce tu **código de participante** (por ejemplo: P01, P02, etc.)
3. Pulsa **Iniciar experimento**.
4. Para cada problema:
   - **Haz clic en una cerilla** para seleccionarla (se resaltará).
   - **Haz clic en un hueco verde** para colocarla allí.
   - Si cometes un error, puedes pulsar **↺ Reiniciar** para volver a empezar la posición.
   - Pulsa **Comprobar** cuando creas que es correcto, o **Abandonar** si decides no continuar.
   - Aparecerá una ventana pidiendo **observaciones**: es muy importante que anotes aquí tus pensamientos, sentimientos, si te has bloqueado, si has tenido un "¡aha!" (momento de insight), etc.
   - Pulsa **Siguiente →** para pasar al siguiente problema.
5. Al terminar los 8 problemas, aparecerá una pantalla con los resultados.
6. **Pulsa Descargar CSV** para descargar el archivo.
7. **Envía el archivo descargado** a través de WhatsApp, correo o como prefieras.

## Notas importantes

- **Tiempo máximo:** 5 minutos por problema. Si se agota, se marca como no resuelto.
- **Solo 1 cerilla:** No puedes mover más de una cerilla por problema.
- **Observaciones:** Cuanto más detalladas sean, mejor para la investigación. Anota:
  - Si estabas bloqueado/a
  - Qué te hizo cambiar de estrategia
  - El momento en que "viste" la solución
  - Cualquier cosa que sientas que es relevante
- **CSV final:** Es obligatorio descargar y enviar este archivo; contiene todos tus resultados y observaciones.
