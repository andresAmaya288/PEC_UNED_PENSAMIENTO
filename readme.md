Demostración de problemas de cerillas basados en aritmética romana.

Archivos principales:
- `index.html`: experimento completo.
- `demo.html`: demo simplificada del motor de cerillas.

Uso:
1. Abrir `index.html` o `demo.html` en el navegador.
2. Seleccionar un problema.
3. Mover una cerilla y validar el resultado.
